# CodeRabbit trial

Temporary file for a one-off test of the CodeRabbit review bot on a
documentation-only pull request. It is not part of the product documentation
and will be removed after the trial. The pull request that adds it is not meant
to be merged.

What the trial checks:

- CodeRabbit replies to a manual `@coderabbitai review` request.
- Its review is a comment only: it does not approve or request changes.
- The required `Tests (windows-latest)` and `Tests (macos-15)` checks still run.
- The pull request stays blocked until the code owner approves it.
