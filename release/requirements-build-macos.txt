# release/build_macos.py installs this into a fresh, isolated build venv.

#   - added for macOS: uvloop (uvicorn[standard] installs it on macOS, not on

#   - left out (Windows only): pefile, pywin32-ctypes.

# pure-Python wheel; nothing is built from source.
# Regenerate deliberately when requirements.txt or release/requirements-build.txt
# changes, then run the full test suite and the macOS build.
# Test-only packages (pytest, httpx, httpx2) are intentionally absent.
